# Mission: Break Password Forge

You have been handed version 0.1.0 of a password-generator extension. Test it in Chrome on a real desktop. You may crash the extension or lose its test settings; use dummy passwords only.

## Objectives

1. Perform a cognitive walkthrough: as a first-time user, generate a password with chosen length and character types, then copy it. Record where the next action or outcome is unclear.
2. Test ordinary generation and copying, then probe boundary values, unusual combinations, repeated actions, state changes, keyboard operation and browser interruptions.
3. Consider whether the extension's security and privacy claims match what it actually does.
4. Record functional defects separately from usability observations and unconfirmed suspicions.

For each finding, note **environment**, **steps to reproduce**, **expected result**, **actual result**, **frequency**, **impact** and evidence where useful. Include at least one tested scenario that behaved correctly.

Inspect the source only after the blind manual pass. There is no required number of flags: a defensible observation with evidence is worth more than a long list of guesses.
